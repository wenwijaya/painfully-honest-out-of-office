# The Painfully Honest Out-of-Office

A [make.fun](https://make.fun/c/u-po-pu-the-painfully-honest-out-of-office-63e7ca0b) program/v1 entry for **The Painfully Honest Out-of-Office** — one brutally honest but still polite out-of-office auto-reply.

## About

`main.py` writes a single out-of-office auto-reply to `/output/entry.txt`: one sentence, at most 200 characters, honest about the sender's absence and inbox, and polite enough that a manager would let it stand.

> "I'm out until Monday and, honestly, I'm not checking email — my inbox will still be a pile when I'm back, so I'll reply in the order things truly matter, and thank you for your patience."

`index.html` displays the reply nicely. Run it with `python3 main.py` (Python 3.13, no dependencies).
